# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer that compares a resume with a job description and provides an ATS-style analysis using Google Gemini.

## 🚀 Live Demo

https://ai-resumecv-analyzer.streamlit.app/

## ✨ Features

- 📄 Upload PDF resumes
- 📝 Paste any job description
- 🎯 ATS Match Score
- ✅ Matching Skills Analysis
- ❌ Missing Skills Detection
- 💪 Strengths & Weaknesses
- 🚀 Resume Improvement Suggestions
- ⭐ Final AI Recommendation

## 🛠️ Tech Stack

- Python
- Streamlit
- FastAPI
- Google Gemini API
- PyPDF
- Requests

```bash

cd AI-Resume-Analyzer

pip install -r requirements.txt

streamlit run app/streamlit_app.py
```
